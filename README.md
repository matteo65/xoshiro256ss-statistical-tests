# Empirical Statistical Verification of the xoshiro256** PRNG

This repository hosts a high-volume collection of independent statistical tests for the xoshiro256** pseudo-random number generator.  
Featuring 300 TestU01 BigCrush suites and 10 multi-gigabyte PractRand deployments across randomized seeds, this dataset serves as a robust reference point for cryptographic benchmarking and PRNG quality comparison.
